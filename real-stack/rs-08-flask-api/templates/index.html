Train. Track. Earn points.

HexaFit is a fitness-tracking platform: members log workouts, collect points, and redeem them for real rewards. Mobile apps talk to this REST API — JSON in, JSON out, a JWT bearer token on every call.

Endpoint map

MethodPathWhat it does
POST/api/auth/registerCreate an account, get a token
POST/api/auth/loginExchange email + password for a JWT
GET/api/auth/meYour own record
GET/api/usersMember directory
GET/api/users/<id>One member's record
GET/api/users/search?name=Search members by name
PATCH/api/users/meUpdate your profile (JSON)
POST/api/users/me/avatarImport an avatar from a URL {"url": …}
GET/api/users/<id>/workoutsA member's workout history
GET · POST/api/workoutsList / log your workouts
GET/api/workouts/<id>One of your workouts
GET/api/workouts/export?file=Download an export file
POST/api/rewards/redeemRedeem points: {"item": "protein-box"} (100), "gym-towel" (250), "premium-month" (1000)
GET/api/admin/statsPlatform statistics — admin tokens only
GET/profile/<id>The public web profile page (companion site)
