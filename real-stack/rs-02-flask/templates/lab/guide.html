📖 Real Website Guide — recognising Flask / Werkzeug

Fingerprint drill — prove it is Flask before you test

  • Server header: Werkzeug/3.x Python/3.12 — the dev server introduces itself by name and version.
  • Default 404: ask for a nonsense URL. Werkzeug's built-in "The requested URL was not found on the server" page is unmistakable.
  • The debugger: with debug mode on, an error page becomes an interactive traceback with source snippets — and /console appears. Trigger an error on purpose and look.
  • Session cookie: real Flask signs its session cookie (it starts with eyJ, base64 JSON, dot-separated signature). HexaNotes invented its own — decode yours and notice what is missing.
  • Errors leak paths: Python tracebacks print absolute file paths (/srv/app/hexanotes/...) — free reconnaissance about the deployment.
  • WhatWeb: whatweb http://localhost:3202 from the gateway terminal names the stack in seconds.

What to test first on a real Flask site

  1. Is debug mode on anywhere reachable? /console plus a leaked PIN is remote code execution.
  2. Anywhere user text is rendered: greetings, PDF/email generators, previews. Jinja2 evaluates {{ … }} eagerly when a developer builds templates from strings.
  3. Session handling: weak or leaked SECRET_KEY means forged cookies on real Flask; homemade cookies (like this app's) mean no cryptography at all.
  4. Passwords: fast unsalted hashes (MD5/SHA1) still show up in startup codebases — one database leak and every password falls in minutes.
  5. The next/redirect parameter on login — the classic place for an open redirect that powers phishing.

Burp workflow for this lab

Proxy the app and map it with the site map. Work the search box and note ids in Repeater; decode and rebuild the session cookie by hand and watch the app accept it; compare the Location headers on login responses in Comparer when you vary the next parameter. For the debugger console, the PIN is printed in the app's own server output — the gateway's console view shows it, exactly the way real server logs leak into the wrong hands.

The professional habit

Note every flaw as: what, where, proof, impact. The Complete page will ask you to write one up properly — that write-up is what a client actually pays for.
