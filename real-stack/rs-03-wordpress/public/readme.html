Version 6.4.2

Welcome to HexaPress, the WordPress-style publishing core that powers WanderPress.

System requirements

  • PHP 8.0 or greater
  • SQLite or MySQL 5.7+
  • A web server that serves wp-content (and, apparently, everything in it)

Upgrade notice

6.4.2 is a maintenance release. Sites that have not upgraded carry publicly documented issues in the REST users route, xmlrpc.php and the media library — see the public changelog for the exact list an assessor would read first.
